notifys

Tiny, dependency-free browser notifications with typed ESM, safe text rendering, predictable lifecycle management and compositor-friendly progress.

TRY THE DEMO GitHub

Everything you need

One timer per toast

No 10 ms polling loop. Timed notifications use a single timeout while progress runs as a CSS transform animation.

Safe by default

Messages render as text unless trusted HTML is explicitly enabled. Caller-owned options are copied and frozen.

Deterministic cleanup

Animations have fallback cleanup, closing notifications stay owned, and destroy() releases timers, DOM and queue state.

Six positions

Move one queue between all viewport corners and centers without rebuilding existing notification state.

Pause on hover

Hover suspension pauses both the remaining lifetime and progress animation, then resumes from the exact remainder.

Expanded notifications

Use titled layouts and custom action renderers when a simple toast is not enough for the interaction.

TypeScript first

Strict types, native ESM exports and declaration files make the public API predictable in modern toolchains.

Framework agnostic

Browser-native DOM code works in vanilla applications and integrates cleanly with Vue, React, Svelte or any SPA.

Zero runtime deps

The package ships its own runtime and CSS with no production dependency graph to pull into your application.
