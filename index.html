Small API.
Hard lifecycle guarantees.

The library stays deliberately narrow: browser notifications, predictable ownership, and no framework-specific runtime.

01 / lifecycle

No 10 ms polling

A single lifetime timer handles expiration while CSS transforms render the progress bar without a JavaScript frame loop.

02 / cleanup

Explicit destruction

destroy() immediately releases active notifications, timers and the container — useful for SPAs and isolated views.

03 / safety

Text is safe by default

Messages are rendered as text unless trusted HTML is explicitly enabled. Caller options are normalized without mutation.

04 / platform

Native ESM + types

Modern JavaScript modules, generated declarations and zero runtime dependencies keep integration straightforward.
